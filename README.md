# TrueSight releases

Installers for TrueSight, an awareness assistant for Dota 2 on Windows.

Download the latest `TrueSight-Setup-<version>.exe` from [Releases](https://github.com/pavel-leskavets/truesight-releases/releases/latest) and install it once. The app updates itself from here after that.

The installer is not code-signed, so Windows may show "Windows protected your PC" on the first install: choose **More info -> Run anyway**.
